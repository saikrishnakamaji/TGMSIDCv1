DEMS — Digital Equipment Management System
PURE HTML/CSS/JavaScript DEMO FOR ASP.NET CORE .NET 8 MICROSERVICES

This package intentionally does NOT use Angular, React, Node.js or any frontend framework.

Run:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge.
3. Use the left menu and dashboard buttons.

UI modules:
Dashboard, Indent Receipt, Create Indent, Indent Approval, Rate Contracts,
Purchase Orders, Delivery & Receipt, QA & Acceptance, Master Data,
Reports & Analytics, Audit Trail.

Suggested production integration:
HTML/CSS/JS -> ASP.NET Core .NET 8 Web API / API Gateway -> Microservices.

Suggested services:
Identity/User, Master Data, Indent, Workflow/Approval, Tender,
Rate Contract, Purchase Order, Vendor, Delivery, QA/Acceptance,
Document, Notification, Audit, Reporting.

The UI is a presentation/demo prototype with sample data. Buttons are visual demo actions.
